## Lab Overview

In this lab, I worked with Bash scripting to automate routine tasks. The main focus was on creating a script that performs a backup of a folder, improving efficiency and reducing the need for manual execution of repetitive commands.

### Steps:

   1. I created a Bash shell script to automate the backup of the CompanyA folder as a compressed archive. The script was designed to generate a backup file with a date-based name, making each archive unique and easy to identify.
      I made the script executable, added the necessary commands and variables, and used the tar utility to create the compressed backup. After running the script, I verified that the archive was successfully created in the designated backups folder.
      This task showed how Bash scripting can be used to automate routine administrative tasks and make backup processes more efficient and repeatable.
