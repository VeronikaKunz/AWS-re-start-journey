## Lab Overview

In this lab, I worked with a relational database to practice using SQL functions for data analysis and transformation. The focus was on applying functions within **SELECT** statements and **WHERE** clauses to summarize, filter, and manipulate data.
I explored aggregate functions such as SUM, MIN, MAX, and AVG, as well as string functions and techniques to handle duplicates. This helped build a deeper understanding of how to extract meaningful insights and refine query results using SQL functions.

 ### Steps:

   1. I queried the world database using SQL functions to process and analyze data. I applied aggregate functions such as **SUM**, **AVG**, **MAX**, **MIN**, and **COUNT** to summarize information across the dataset.
      I also used string functions like **SUBSTRING_INDEX** to extract parts of text and applied conditions to filter results based on specific patterns. Additionally, I used **LENGTH** and **TRIM** to evaluate string size and **DISTINCT** to remove duplicate records, improving the clarity and usefulness of the query results.
