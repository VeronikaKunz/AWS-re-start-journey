## Lab Overview

In this lab, I worked with a relational database to organize and analyze data using SQL. The focus was on grouping records and applying advanced query techniques to gain structured insights.
I explored the use of the **GROUP BY** clause with aggregate functions and applied window functions such as **RANK()** and **SUM()** with the **OVER** clause to perform more advanced data analysis.

### Steps:

   1. I queried the world database to organize and analyze data using grouping and window functions. I filtered records based on specific conditions and sorted the results to improve readability.
      I used the **GROUP BY** clause together with aggregate functions to calculate totals for grouped data. Additionally, I applied window functions with the OVER clause to generate running totals and rankings within a dataset, allowing for more advanced analysis of the data.
