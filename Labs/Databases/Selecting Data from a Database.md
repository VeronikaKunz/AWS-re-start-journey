## Lab Overview

In this lab, I worked with a relational database to practice querying data using SQL. The focus was on using the **SELECT** statement along with common operators and functions to retrieve and analyze data from existing tables.
Using a pre-configured database environment, I explored how to filter, sort, and count data, gaining a better understanding of how to extract meaningful information from a database.

### Steps:

   1. I queried the **world** database using various **SQL SELECT** statements to retrieve and analyze data. I explored how to display all records, count rows, and view the table structure to better understand the schema.
      I also selected specific columns, applied aliases for better readability, and organized the results using sorting options. Additionally, I used filtering conditions and comparison operators to extract targeted data, demonstrating how to refine queries based on specific criteria.
