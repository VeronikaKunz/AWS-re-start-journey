## Lab Overview

In this lab, I worked with a relational database to practice core database and table operations. The focus was on managing database structures using SQL commands such as CREATE, SHOW, ALTER, and DROP.
Working in a pre-configured environment with a database client, I explored how databases and tables are organized, modified, and maintained within a database instance.

### Steps:

  1. I created a new database and defined a structured table within it to store data. I verified the database and table creation using SQL queries and explored the table schema to review its columns and properties.
