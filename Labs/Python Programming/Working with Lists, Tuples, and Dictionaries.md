## Lab Overview

This lab introduces collections in Python, which are used to store and manage groups of data.

I explored three common collection types: lists, tuples, and dictionaries, learning how they organize and handle multiple values within a single structure.

### Steps:

1. I created a list containing several fruit names and printed it to the console.
   Using the **type()** function, I verified that Python recognizes this collection as a list. This demonstrated how multiple values can be stored and managed within a single variable.
