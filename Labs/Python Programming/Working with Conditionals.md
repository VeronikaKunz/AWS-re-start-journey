## Lab Overview

This lab introduces conditional statements in Python, which allow a program to make decisions based on comparisons.

I practiced using **if**, **elif**, and **else** statements along with comparison operators to control the flow of the program and create different execution paths depending on the input.

### Steps:

1. I used the **input()** function to capture user input and determine whether a package needs to be shipped.
   Using an **if** statement, I compared the user’s response to "yes" and displayed a message when the condition was met. If the input was "no", no output was produced, showing how the program follows a specific path only when the condition is true.
   This demonstrated how if statements control program flow based on user input.

2. I improved the script by adding an **else** statement to handle the case when the user does not want to ship a package.
   Now, the program provides a response for both possible inputs. If the user enters "yes", it confirms assistance, and if the user enters "no", it displays a polite message.
   This demonstrated how the else statement ensures that all possible conditions are handled.

   Based on the user’s input, the program now provides different responses for stamps, envelopes, or copies. For the copy option, I also added a second input to ask for the number of copies and included it in the output.
   This demonstrated how **if**, **elif**, and **else** work together to handle multiple conditions, with only one path being executed at a time.
