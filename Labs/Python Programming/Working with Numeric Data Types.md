## Lab Overview

This lab focuses on using Python for basic mathematical operations and understanding how numeric data is stored.

I explored different data types used for numbers, including integers, floats, and complex numbers, as well as boolean values. The lab also introduced the Python shell, providing a simple way to test and work with these data types interactively.

### Steps:

1. I started the Python shell in the terminal using the **python3** command, which opened an interactive environment for testing code.
   Using the prompt, I practiced basic mathematical operations such as addition, subtraction, multiplication, and division. The results were displayed immediately, helping me understand how Python handles numeric calculations (for example, division returning a float).
   After completing the exercises, I exited the shell using the **quit()** command.
