## Lab Overview

This lab introduces the use of the **Python Debugger (pdb)** to identify and fix errors in code.

I explored how to step through a Python script line by line, inspect variables, and better understand program flow. This helps in locating bugs and verifying that the code behaves as expected.

The lab demonstrates how debugging tools can improve code quality and make troubleshooting more efficient.
