## Lab Overview

This lab introduces the basics of programming using Python by creating a simple “Hello, World” program.

It provides a first hands-on experience with writing and running Python code, helping build a foundation for understanding core programming concepts.

### Steps: 
1. The lab environment was started and the AWS Management Console was opened automatically. From there, the Cloud9 service was accessed and the provided development environment was launched.
   The AWS Cloud9 IDE opened successfully, allowing direct interaction with a preconfigured Python workspace. Any initial pop-up prompts were dismissed to proceed with the setup.

2. A new Python file was created in the AWS Cloud9 IDE using the provided template. The default sample code was removed, and the file was saved with a meaningful name (e.g., hello-world.py) in the working directory.
   This file serves as the starting point for writing and running Python code.

   <img width="500" height="207" alt="Screenshot 2026-04-14 at 11 28 07" src="https://github.com/user-attachments/assets/777b41a4-256f-4528-ab34-70315ba3858e" />

3. Python is a high-level, general-purpose programming language known for its simple and readable syntax.
   I explored the available Python versions in the environment by running commands such as **python --version, python2 --version, and python3 --version**. This helped confirm which versions were installed and ensured that Python 3 was being used for the lab.

4. I opened the Python file created earlier and added a simple line of code to print a message: **Hello, World**.
   After saving the file, I executed the program using the Run button in the IDE. The output was displayed in the terminal, confirming that the program ran successfully and the environment was set up correctly.
