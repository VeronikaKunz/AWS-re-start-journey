## Lab Overview

This lab focuses on working with strings in Python, which are used to store and handle text.

I practiced writing Python code that uses strings, combining them through concatenation, capturing user input, and formatting output to create clear and readable results.

### Steps:

1. I created a variable containing text and printed it to the console to confirm the script runs correctly.
   Using the type() function, I checked the data type of the variable and verified that Python recognizes it as a string (str). I then combined the text with its data type in a single output using the str() function.
   This demonstrated how Python stores and handles textual data.
