## Lab Overview

This lab introduces loops in Python, which allow code to repeat based on a condition or over a sequence.

I explored both while and for loops, learning how they control repetition and automate tasks within a program.

### Steps:

1. I started by creating a simple introduction for the game using the **print()** function.
   The script displays a welcome message and explains the rules, preparing the user for the number guessing game. This sets the foundation for adding a loop that will handle repeated guesses.

2. I imported the random module to generate a number between 1 and 10 using **randint()**.
   I then created a variable to track whether the correct number was guessed and implemented a while loop to repeatedly prompt the user for input. The loop continues until the correct number is entered.
   Using an **if-else** condition inside the loop, the program checks the user’s guess and provides feedback, either prompting another attempt or confirming a correct guess.

3. I used a for loop together with the **range()** function to print numbers from 0 to 10.
   The loop iterates through a sequence of numbers, assigning each value to the variable **x** and printing it. Since the end value in **range()** is not included, I used 11 to ensure the loop counts up to 10.
   This demonstrated how for loops can efficiently handle repeated actions over a sequence.
