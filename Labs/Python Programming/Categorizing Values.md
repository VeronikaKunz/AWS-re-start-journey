## Lab Overview

This lab focuses on combining different data types in Python within a single list.

I worked with numeric and string values, stored them in a list, and used a for loop along with the print() function to iterate through and display each element.

### Steps:

1. I created a list containing different types of values, including **integers**, a **float**, a **boolean**, and **strings**.
   Using a for loop, I went through each item in the list and printed both the value and its data type with the **print()** function and **format()**. This showed that Python lists can store mixed data types and that each element keeps its own type.
